# BG3 — прозрачные спрайты для Tavo

Это независимая библиотека изображений персонажей для RPG Baldur's Gate 3.

Положите в эту папку файлы:
- `astarion_smirk.webp` — ухмылка Астариона
- `astarion_playful.webp` — игривость Астариона

Оба файла подготовлены в архиве BG3_Sprites_Web_Host_Ready.zip. Ссылки заработают только после загрузки изображений в эту папку.

Прямые адреса после загрузки:
- https://raw.githubusercontent.com/notalive23-maker/pandora-pw/main/bg3-sprites/astarion_smirk.webp
- https://raw.githubusercontent.com/notalive23-maker/pandora-pw/main/bg3-sprites/astarion_playful.webp

`sprites.json` — реестр файлов и эмоций. Это НЕ лорбук для прямого импорта в Tavo. Для автоматического отображения требуется визуальный модуль Tavo, который получает эмоцию из сцены и преобразует её в адрес соответствующего WebP.

Изображения будут публичными, так как репозиторий публичный.
